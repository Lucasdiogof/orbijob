# B · Trajetórias — tipografia

Manrope 600/800 para títulos e logotipo; Manrope 400/500 para texto.

| Papel | Família | Licença |
|---|---|---|
| Títulos / logotipo | Manrope | SIL OFL 1.1 |
| Texto | Manrope | SIL OFL 1.1 |
| Dados / rótulos | JetBrains Mono | SIL OFL 1.1 |

Escala (dp): displayLarge 32/40 · headline 24/32 · title 18/24 · body 15/22 · bodySmall 13/18 · label 12/16.

Arquivos `woff2` (latino) e licenças em `docs/design/fonts/`. Wordmarks do logotipo são **curvas vetoriais** (sem dependência de fonte instalada). Para o app final, incluir as famílias completas se for necessário suportar alfabetos além do latino (CJK, árabe etc.) com fontes de fallback adequadas (ex.: Noto, também OFL).
