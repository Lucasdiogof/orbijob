# Fontes das propostas de identidade

Todas sob **SIL Open Font License 1.1** (uso comercial e redistribuição permitidos, sem venda isolada da fonte). Arquivos `woff2` (subconjunto latino) vêm dos pacotes npm `@fontsource/*` (Sora, Manrope, Space Grotesk, Inter, JetBrains Mono); o texto de licença de cada família está em `LICENSE-*.txt`. Servem às prévias HTML e à conversão dos logotipos em curvas. Para o app final, usar as famílias completas (incluindo caracteres não latinos, quando necessário).
