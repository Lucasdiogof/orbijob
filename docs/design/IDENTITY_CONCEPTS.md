# Três conceitos de identidade (nenhum escolhido)

Nomes de trabalho alternativos são **apenas sugestões a verificar** (disponibilidade não checada). Paletas são placeholders de proposta; contraste AA a ser verificado com ferramenta antes da adoção. Nenhum asset gráfico foi produzido nesta fase.

## Conceito A — "Sonar" (JobRadar / alternativa: *Vagaroo*, *Trabalhar.World*)
- **Ideia:** ondas concêntricas de radar formando uma pin de localização; sensação de "varredura do mundo".
- **Logo:** círculo com 3 arcos e um ponto; versão ícone = ponto + 1 arco.
- **Paleta:** Azul-profundo `#0B2A5B`, Ciano `#18B6D4`, Off-white `#F5F8FB`, Âmbar de destaque `#FFB020`; escuro: fundo `#0A1424`.
- **Tipografia:** Sora (títulos) + Inter (texto).
- **Justificativa:** comunica abrangência global e monitoramento; confiável e neutro para qualquer profissão. **Risco:** radar/sonar é o clichê do segmento (conflito com produtos "radar").

## Conceito B — "Trilha" (alternativa: *Rumo*, *Caminhos*)
- **Ideia:** linha contínua que sobe como degraus/rota, representando carreira e candidatura em etapas (kanban de candidaturas).
- **Logo:** monograma "R" formado por um caminho único.
- **Paleta:** Verde-floresta `#0F5132`, Verde-lima `#8BD450`, Areia `#F6F1E7`, Grafite `#1F2933`; escuro: fundo `#101A14`.
- **Tipografia:** Manrope + Source Serif 4 para destaques editoriais.
- **Justificativa:** humano e acolhedor, funciona tanto para pedreiro quanto para enfermeira; foge do visual "tech azul". **Risco:** verde evoca finanças/saúde em alguns mercados.

## Conceito C — "Mosaico" (alternativa: *Tessera*, *Ofício*)
- **Ideia:** mosaico de pequenos quadrados coloridos representando muitas profissões formando um globo/uma letra.
- **Logo:** grade 3×3 com cantos arredondados, uma célula em destaque.
- **Paleta:** Índigo `#3B2F8F`, Coral `#FF6B57`, Turquesa `#2EC4B6`, Creme `#FFF8F0`, Tinta `#16132B`; escuro: fundo `#12101F`.
- **Tipografia:** Plus Jakarta Sans.
- **Justificativa:** celebra diversidade de ofícios, marca mais ownable e fácil de registrar; visual mais expressivo. **Risco:** exige disciplina para manter minimalismo.

## Decisão
Pendente do proprietário. Após escolher: gerar logo/ícone vetoriais, tokens de cor M3 (`ColorScheme.fromSeed` + ajustes), verificar contraste, substituir `kProvisionalSeed` em `app/lib/core/theme/app_theme.dart`.
